- The official ETHGlobal film **How Ethereum Grows Without a Center** as the main feature.
- Shaka's verified testimony and recorded Bogotá recollection, kept distinct from Aya's public teachings.

## Run locally

No build step and no package install are required.

```sh
python3 -m http.server 8080
# open http://127.0.0.1:8080/
```

`index.html` contains semantic content. `assets/garden.css` owns presentation. `assets/garden.js` progressively enhances the video facade, tribute tabs, and public tray. The page remains readable and all primary video/source links work with JavaScript disabled.
